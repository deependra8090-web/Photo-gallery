# 📸 Photo Gallery

A responsive photo gallery built with **React, Vite, and Tailwind CSS** using the Picsum Photos API.

## Features

- 📷 Fetch 30 photos from Picsum API
- 🔍 Search photos by author
- ❤️ Add/remove favourites
- 💾 Favourites persist using `localStorage`
- 🔄 Loading and error states
- 📱 Responsive grid
- ⚡ `useReducer`, `useMemo`, `useCallback`
- 🧩 Custom `useFetchPhotos` hook

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Picsum Photos API

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
